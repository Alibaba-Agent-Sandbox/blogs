## Structure

The module is deliberately small and has three parts:

- **Module docstring** — one line stating the module's intent, matching the
  documentation style used elsewhere in this workspace.
- **`GREETING`** — a module-level constant holding the exact output text
  `Hello from the sandbox`. Keeping the literal in a named constant means the
  string appears once, so it can be compared against expected output directly.
- **`main()`** — annotated `-> None`; emits `GREETING` with a single `print`
  call. `print` appends exactly one newline, so the program's complete output is
  the greeting followed by a line terminator.
- **`if __name__ == "__main__":` guard** — calls `main()` only when the file is
  executed as a script. Importing the module for testing or inspection defines
  `GREETING` and `main` without producing output, which makes the module usable
  as a test fixture.
