## Overview
`generated_hello.py` is a minimal Python program that writes a single fixed
greeting to standard output. It exists to demonstrate that a script can be
created and executed inside the sandbox workspace.

## Files

- `GENERATED_REPORT.md` — this document.

## Behavior
- Prints exactly `Hello from the sandbox` followed by a newline.
- Produces no other output, reads no input, and touches no files or network.
- Always exits with status `0`.

- `if __name__ == "__main__":` guard — runs `main()` only when the file is
