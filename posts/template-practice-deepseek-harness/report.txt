## Behavior

  no standard input, and no files.
- **Output:** exactly one line on stdout, terminated by a single newline:


- **Side effects:** none. No files, sockets, or subprocesses are created.

## Implementation

```python
#!/usr/bin/env python3
"""Print a single greeting line and exit successfully."""


def main() -> None:
    print("Hello from the sandbox")


if __name__ == "__main__":
    main()
```

Design notes:

1. **`main()` function** — keeps the logic importable. Importing the module
   (`import generated_hello`) defines `main` without printing anything, because
   the call is guarded by `if __name__ == "__main__":`. This makes the module
   usable in tests and in larger programs.
2. **Single `print` call** — `print` appends exactly one `\n`, so the output is
   one line and nothing else. The literal is spelled `Hello from the sandbox`
   with no trailing punctuation and no leading indentation.
3. **`-> None` annotations and a docstring** — self-documenting and compatible
   with type checkers such as `mypy` and linters such as `ruff`/`flake8`.
4. **No third-party imports** — only Python's standard library is used, so the
   script runs on any CPython 3.x installation.
