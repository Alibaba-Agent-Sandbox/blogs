# Run the current generated-application example

Use CLI 0.5.3 and public Python client 0.4.0a2. Set the provider/model configuration and `ABX_SERVER_TOKEN` shown in the article, then run `python run.py --output ./new-run --cli abx` with a new output directory. The runner generates fresh code, verifies it and deletes only its own sandbox/template.

`generated-public-20261025-0.5.3/` is the current immutable captured example linked by the article, with actual file hashes and public-runtime verification. Other `generated*` directories retain earlier historical model outputs; they are not the current installation or deployment instructions. Their bytes are preserved as evidence.
