# Decision: Add three more completed template cases

Status: proposed

## Problem
The per-template series needs useful native/data/file cases and real coding
configuration, beyond the first Python/OpenCode articles.

## Decision
Add separate practical cases for managed base CSV/Decimal-to-JSON processing,
Aider read-only review/selected writeback/model changes, and native apply-patch
file workflows. Attach actual outputs and complete SDK/program files. Keep
execution detail in the template owner and preserve historical articles.

## API Design
N/A — three Chinese case posts and relative downloadable assets, using the
existing website fallback and blog ingestion schema.

## Alternatives considered
Do not publish boilerplate placeholders or claim a model/HTTP server is needed
by tools that do not declare one. Do not label core-only matrix runs complete.

## Dependencies
Refs https://github.com/Alibaba-Agent-Sandbox/blogs/issues/16 and
https://github.com/Alibaba-Agent-Sandbox/awesome-templates/pull/250.
The source evidence owner must land before this consumer merges.

## Test Strategy
Validate13 posts, compare actual output hashes, independently run generated code,
compile snippets, run the complete base article program on a real managed
instance and verify its absence. Sync/build isolated website preview and inspect
bilingual routes/assets.

## Acceptance criteria
All three cases contain installation/configuration, runnable work, actual results,
secondary development, limits and cleanup. Their source/provider/model claims
match evidence. Five of50 cases are delivered after this increment; remaining
cases stay tracked rather than being described as complete.
