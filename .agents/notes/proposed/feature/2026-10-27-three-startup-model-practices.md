# Decision: Publish three complete startup-configured coding practices

Status: proposed

## Problem
Qwen, DeepSeek harness and Hermes need their own practical experience with working
model/endpoint/key setup, real source repair, artifacts, compatibility run and cleanup.

## Decision
Publish three distinct cases with native/author-owned identity boundaries, exact
executed SDK programs and real generated code/reports. Show explicit custom model
settings, two startup models and compatibility Python execution through public methods.

## API Design
N/A — content/assets only. Preserve actual typed arguments, startup/per-call rules,
protocols and provider selection. Hermes custom provider is explicit; no vendor
account or OpenRouter entitlement inferred. DeepSeek harness is not a vendor CLI.

## Alternatives considered
Version-only posts, a response without files or templates still ignoring selected
models cannot convey a usable newcomer experience. Preserve failures in source evidence.

## Dependencies
https://github.com/Alibaba-Agent-Sandbox/awesome-templates/pull/262 owns actual source
changes, provider receipts and all4 methods per template. Source acceptance precedes
article merge. Refs https://github.com/Alibaba-Agent-Sandbox/blogs/issues/16.

## Test Strategy
Review actual model/source repair/unchanged original and independent held-out checks,
fresh literal CLI/full unchanged SDK/HTTP generation plus compatibility method calls,
actual model initialization where available, artifact execution and independent cleanup.
Validate41posts, website sync/build and both language routes/assets; scan secrets.

## Acceptance criteria
Three cases publish after source/current-head checks. Registry promotion separately
reviews matching identities and all method proof; full50-template series stays open.
