# Decision: Publish native browser and gateway cases

Status: proposed

## Problem
Browser-use, Stagehand and OpenClaw need individual real business narratives with
newcomer configuration, actual effects, reusable integration and extension guidance.

## Decision
Publish one case each, original complete SDK programs, original IANA screenshots
and actual structured expense results. Explain accounts/model switching/protocols,
session lifetime and exact cleanup; avoid testing-diary framing.

## API Design
N/A — existing public template commands. Browser-use bounded recovery and native
OpenClaw conversation methods depend on the source owner PRs below.

## Alternatives considered
Gateway health, generated prose or a stale web-page assumption cannot establish
working browser interactions or native conversation continuation.

## Dependencies
https://github.com/Alibaba-Agent-Sandbox/awesome-templates/pull/265 and
https://github.com/Alibaba-Agent-Sandbox/awesome-templates/pull/272 require merge
before this article PR. Refs https://github.com/Alibaba-Agent-Sandbox/blogs/issues/16.

## Test Strategy
Source-bound actual native/model/all-method/docs receipts; independent page state
and PNG decoding, native expense context and arithmetic; original assets inspected.
Validate47 posts, website1255-page preview, three bilingual routes/six exact assets,
configured-secret/diff checks and current-head CI.

## Acceptance criteria
Both producer PRs merge, article CI/review, merge, website deployment and public
readback. Full50-template series remains incomplete.
